## Notes

- Commit ids in the report's table are the ones you reported; the script does not read git history.
- The lock record's `git_at_lock` is the commit before the Day 7 commit; the tag goes on the Day 7 commit.
- After the lock, a prompt or model change is a new, separately named version, never an edit of `baseline_v3`. `verify` and the real-lock tests fail if a locked file, reference run, Week 1 file or the frozen access log changes.
